# h3s-fit

This project is a Python implementation of potential energy surface (PES) fitting with permutational invariant polynomials neural network (PIP-NN).  
`H + H2S` system is used in this project.

## Installation

Here is an environment file `env.yml` inside the main directory, simply use the command below to create a conda virtual environment.

```bash
$ conda env create -n cqpes -f env.yml
```
